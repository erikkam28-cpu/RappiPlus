# RappiPlus
RappiPlus es un servicio de suscripción diseñado para aumentar la frecuencia de compra y el valor generado por el usuario.


---

## ❓ Preguntas Clave
- ¿Los usuarios realmente compran más?
- ¿El modelo está generando ganancias?
- ¿Se están perdiendo oportunidades en el proceso de compra?

---

## 📊 Metodología
1. **Preprocesamiento de datos**  
   - Limpieza y estandarización de datos.  
   - Eliminación de inconsistencias, duplicados y valores faltantes.  

2. **Exploratory Data Analysis (EDA)**  
   - Análisis de características demográficas y de uso.  
   - Identificación de patrones en clientes que permanecen y los que cancelan.  

3. **Análisis de Rentabilidad del Negocio**  
   - Cálculo de KPIs (ingresos, costos, ganancias).  
   - Identificación de segmentos rentables.  

4. **Análisis del Funnel de Conversión**  
   - Uso de SQL para mapear el recorrido del usuario.  
   - Detección de puntos de abandono y mayor drop-off.  

5. **Análisis de Retención por Cohortes**  
   - Construcción de cohortes con SQL.  
   - Evaluación del comportamiento en el tiempo.  

6. **Evaluación de Impacto (Experimentación A/B)**  
   - Análisis de hipótesis con Python.  
   - Obtención de recomendaciones estratégicas.  

7. **Construcción del Dashboard y Comunicación de Insights**  
   - Visualización de resultados en Power BI.  
   - Presentación clara para stakeholders.  

---

## 🛠️ Herramientas Utilizadas
- **Python**  
- **Pandas**  
- **SQL**  
- **KPIs (Revenue, Cost, Profit)**  
- **Power BI**
